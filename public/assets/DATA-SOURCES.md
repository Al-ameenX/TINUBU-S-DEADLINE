The LGA directory was adapted from temikeezy/nigeria-geojson-data (MIT license, DIRECTORY-LICENSE.txt). State spelling Nassarawa was normalized to Nasarawa. The directory includes 774 LGAs, including the six FCT area councils.

State boundaries were adapted from markmarkoh/datamaps src/js/data/nga.json, Natural Earth geographic data (public domain). Boundary simplification is intended for navigation, not legal boundary determination.

No election results are bundled with this website. All results originate from administrator uploads and require editorial review.
